# MultiTF Framework Assistant

多周期（H4/H1/M15/M5）趋势跟踪 MT5 EA，中文注释，提醒优先，可选自动交易。

## 功能概览

- 多周期趋势识别：大方向（H4）→ 趋势确认（H1）→ 形态/位置（M15）→ 入场触发（M5）
- 三种策略：顺势回调 / 突破延续 / 反转确认，可单独开关
- 仓位管理：按风险百分比或固定手数
- 单笔利润保护：保本止损 + 移动止盈（TP1/TP2/不设固定止盈）
- 账户利润保护：净值高水位回撤保护（三种基准锚定模式）
- 单日最大亏损保护（百分比 / 固定金额）
- 连续亏损后自动暂停开仓

## 目录结构

```
.
├── Experts/        # EA 主文件（.mq5），放入 MT5 的 MQL5/Experts 目录
├── Include/        # 若拆分出公共函数/头文件，放在这里
├── docs/           # 版本说明、参数说明等文档
├── tests/          # 策略测试报告、回测配置(.set)等
├── CHANGELOG.md    # 版本更新记录
├── LICENSE
└── README.md
```

## 安装使用

1. 将 `Experts/MultiTF_Framework_Assistant_V0.1.mq5` 复制到 MT5 客户端的
   `MQL5/Experts/` 目录（可通过 MetaEditor 的“文件 -> 打开数据文件夹”找到）。
2. 在 MetaEditor 中打开并编译（F7），生成 `.ex5`。
3. 在 MT5 中将 EA 拖到目标品种图表上，按需调整输入参数。
