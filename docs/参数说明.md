# 参数说明

以下按 EA 输入面板的分组顺序说明各参数含义，详细中文说明也可直接查看
EA 源码中每个 input 后的行内注释。

## 一、策略模式与界面显示
- `InpMode`：选择运行的策略组合（全部 / 顺势回调 / 突破延续 / 反转确认）
- `InpEnableAutoTrade`：是否自动开仓
- `InpUseAlerts`：信号出现时是否弹窗提醒
- `InpDrawLevels`：是否在图表上画入场/止损/止盈线

## 二、仓位管理与交易过滤
- `InpUseRiskPercent` / `InpRiskPercent` / `InpFixedLots`：手数计算方式
- `InpMaxOpenPositions`：本 EA 同品种最大持仓数
- `InpMinRR`：最小盈亏比
- `InpMaxSpreadPoints`：最大允许点差
- `InpMinSLPoints` / `InpMaxSLPoints`：止损距离范围

## 三、多周期趋势识别
- `InpBigTrendTF` / `InpTrendTF` / `InpSetupTF` / `InpEntryTF`：四个分析周期
- `InpFastEMA` / `InpSlowEMA` / `InpRSIPeriod` / `InpLookbackBars`

## 四、入场确认与止损缓冲
- 突破缓冲、止损缓冲、反转确认相关参数

## 五、单笔利润保护
- 保本止损、移动止盈相关参数

## 六、账户利润保护（净值高水位）
- `InpEquityProtectAnchorMode`：三种基准锚定模式
- `InpEquityProtectStartPercent` / `InpEquityGivebackPercent` / `InpPauseAfterEquityProtectMinutes`

## 七、单日最大亏损保护
- `InpUseDailyMaxLoss` / `InpDailyMaxLossMode` / `InpDailyMaxLossPercent` / `InpDailyMaxLossMoney`

## 八、连续亏损暂停
- `InpUseConsecutiveLossPause` / `InpConsecutiveLossCount` / `InpPauseAfterConsecutiveLossMinutes`

## 九、EA 运行设置
- `InpTimerSeconds`：定时检查间隔
- `InpMagic`：魔术号
