# 多周期交易系统 EA（V0.1）使用说明

文件：

- `MultiTF_Framework_Assistant_V0.1.mq5`

用途：

- 每隔固定时间（默认 10 秒）检查 H4 / H1 / M15 / M5。
- 用 EMA20、EMA60、RSI14 和近期高低点结构判断趋势（上涨 / 下跌 / 震荡 / 转换）。
- 按三种策略给出信号：顺势回调、突破延续、反转确认，可整体或单独运行。
- 可弹窗提醒、打印日志、在图表画入场/止损/止盈线。
- 可按信号自动开仓，并带多层风控：保本 + 移动止盈、净值高水位保护、单日最大亏损保护、连续亏损暂停。

## 功能概览（对应 V0.1 代码）

- **策略与界面**：`InpMode` 切换策略组合；`InpEnableAutoTrade` 自动交易；`InpUseAlerts` 弹窗；`InpDrawLevels` 画线。
- **多周期识别**：大方向（H4）→ 趋势确认（H1）→ 形态/位置（M15）→ 入场触发（M5）。
- **仓位与过滤**：按风险百分比或固定手数；最小盈亏比、最大点差、止损距离范围、滑点上限过滤。
- **单笔利润保护**：保本止损 + 移动止盈；固定止盈可选 TP1 / TP2 / 不设固定止盈。
- **账户利润保护**：净值高水位回吐保护，支持三种基准锚定模式。
- **风控**：单日最大亏损保护（百分比 / 固定金额）、连续亏损后自动暂停开仓。

## 安装

1. 打开 MT5。
2. 点击 `文件 -> 打开数据文件夹`。
3. 进入 `MQL5/Experts/`。
4. 把 `MultiTF_Framework_Assistant_V0.1.mq5` 放进去。
5. 打开 MetaEditor，编译这个 EA（F7），生成 `.ex5`。
6. 回到 MT5，刷新导航器，把 EA 拖到 `XAUUSD` 图表上。

## 推荐参数：先回测

策略测试器里先用这些参数打底（其余参数先用代码默认值）：

- `InpMode = MODE_ALL`
- `InpEnableAutoTrade = true`
- `InpUseRiskPercent = true`
- `InpRiskPercent = 0.5` 到 `1.0`（代码默认 2.0，保守可先用 1.0）
- `InpMaxOpenPositions = 1`
- `InpMinRR = 1.5`
- `InpMaxSpreadPoints = 250`
- `InpFastEMA = 20`
- `InpSlowEMA = 60`
- `InpRSIPeriod = 14`
- `InpLookbackBars = 120`
- `InpBigTrendTF = PERIOD_H4`
- `InpTrendTF = PERIOD_H1`
- `InpSetupTF = PERIOD_M15`
- `InpEntryTF = PERIOD_M5`
- `InpTimerSeconds = 10`
- `InpTakeProfitMode = TP_USE_TP1`
- `InpEquityProtectAnchorMode = ANCHOR_INITIAL_DEPOSIT`

回测建议：

- 品种：`XAUUSD`
- 周期：`M5`
- 模式：`Every tick based on real ticks`，如果数据太慢可先用 `1 minute OHLC`
- 日期：至少覆盖 3-6 个月
- 初始资金：按你的真实账户或模拟账户设置
- 先分别测试三种模式，再测试 `MODE_ALL`

## 模拟盘前向测试

回测通过后，放模拟盘运行：

- 先跑 1-2 周。
- 每天记录信号、入场、止损、止盈、是否符合肉眼判断。
- 如果连续出现“追在压力位”“震荡区频繁开单”，先关掉 `MODE_ALL`，只测试 `MODE_TREND_PULLBACK`。

## 参数说明（按 EA 输入面板分组）

MT5 参数窗口显示的是变量名，但每个 input 后面都带中文行内注释，在 MetaEditor 里可直接看到。以下按 V0.1 输入面板的九个分组说明。

### 【一】策略模式与界面显示

- `InpMode`：策略组合。`MODE_ALL` 全部；`MODE_TREND_PULLBACK` 顺势回调；`MODE_BREAKOUT_CONTINUATION` 突破延续；`MODE_REVERSAL_CONFIRMATION` 反转确认。
- `InpEnableAutoTrade`：满足信号时是否自动开仓。
- `InpUseAlerts`：出现信号时是否弹窗提醒。
- `InpDrawLevels`：是否在图表画入场/止损/止盈线（对象以 `MTF_` 开头，每轮分析先清旧再画新）。

### 【二】仓位管理与交易过滤

- `InpUseRiskPercent`：`true` 按风险百分比算手数；`false` 用 `InpFixedLots` 固定手数。
- `InpRiskPercent`：单笔最大风险占账户余额的百分比（默认 2.0）。
- `InpFixedLots`：固定手数，仅在关闭风险百分比时生效（默认 0.01）。
- `InpMaxOpenPositions`：本 EA 同品种最多同时持仓数。默认 1，想允许多单并存改成 2、3 或更高。
- `InpMinRR`：最小盈亏比，低于该值不进。
- `InpMaxSpreadPoints`：最大允许点差，点差过大不进。
- `InpMinSLPoints` / `InpMaxSLPoints`：止损距离范围。太近（易被噪音扫损）或太远都放弃。
- `InpDeviationPoints`：允许滑点，市价开仓时使用。

### 【三】多周期趋势识别

- `InpBigTrendTF`：大方向周期，默认 H4。
- `InpTrendTF`：趋势确认周期，默认 H1。
- `InpSetupTF`：形态/位置周期，默认 M15。
- `InpEntryTF`：入场触发周期，默认 M5。
- `InpFastEMA` / `InpSlowEMA`：快/慢速 EMA（默认 20 / 60）。
- `InpRSIPeriod`：RSI 周期，用于反转/背离判断（默认 14）。
- `InpLookbackBars`：回看多少根 K 线找高低点结构（默认 120）。

### 【四】入场确认与止损缓冲

- `InpBreakoutBufferPoints`：突破关键位后额外确认的缓冲（默认 80）。
- `InpSLBufferPoints`：止损放结构外侧时的额外缓冲（默认 120）。
- `InpReversalBreakBufferPoints`：策略3反转入场，突破小高/小低的额外确认点数（默认 120）。
- `InpReversalRequireEMA60`：策略3是否要求收复/跌破慢速 EMA60（默认 `true`，更严格；`false` 时只要求 EMA20，更容易出信号）。
- `InpReversalBuyRsiMax`：策略3做多，背离前 RSI 需低于该值，越小越严格（默认 45）。
- `InpReversalSellRsiMin`：策略3做空，背离前 RSI 需高于该值，越大越严格（默认 55）。

### 【五】单笔利润保护：保本与移动止盈

- `InpUseBreakEven`：启用保本止损（默认 `false`）。
- `InpBreakEvenStartPoints`：浮盈达到该点数后把止损推到保本区（默认 2000）。
- `InpBreakEvenLockPoints`：推保本时锁定的利润点数（默认 50）。
- `InpUseTrailingStop`：启用移动止盈/移动止损（默认 `true`）。
- `InpTakeProfitMode`：固定止盈方式。`TP_USE_TP1` 用 TP1；`TP_USE_TP2` 用 TP2；`TP_NO_FIXED` 不设固定止盈，只靠保本/移动止盈。
- `InpTrailStartPoints`：浮盈达到该点数后启动移动止盈（默认 4000）。
- `InpTrailDistancePoints`：移动止损距当前价多少点（默认 500）。
- `InpTrailStepPoints`：止损相对上次至少改善多少点才修改一次，避免频繁改单（默认 200）。

### 【六】账户利润保护：净值高水位

- `InpUseEquityProtection`：启用净值高水位保护（默认 `true`）。
- `InpEquityProtectAnchorMode`：门槛/净值高点的基准。
  - `ANCHOR_INITIAL_DEPOSIT`（默认）：始终锚定 EA 启动时的初始入金，不随触发重置。
  - `ANCHOR_ROLLING_AFTER_TRIGGER`：每次触发保护后按当时余额滚动更新基准。
  - `ANCHOR_LAST_TRADE_OPEN`：以最近一次本 EA 开仓时的余额为基准（新开仓会重置净值高点）。
- `InpEquityProtectStartPercent`：净值盈利达到基准资金的该百分比后，保护才“武装”（默认 4.0%）。
- `InpEquityGivebackPercent`：从净值高点回吐该百分比后，平掉本 EA 全部持仓（默认 20）。
- `InpPauseAfterEquityProtectMinutes`：触发后暂停开新仓的分钟数（默认 240）。

### 【七】单日最大亏损保护

- `InpUseDailyMaxLoss`：启用单日最大亏损保护（默认 `false`）。触发后当日不再开新仓，跨交易日后自动重置基准。
- `InpDailyMaxLossMode`：`DAILY_LOSS_PERCENT` 按当日开始净值的百分比；`DAILY_LOSS_MONEY` 按固定金额（账户货币）。
- `InpDailyMaxLossPercent`：单日最大亏损百分比，基于当日开始净值（默认 5.0）。
- `InpDailyMaxLossMoney`：单日最大亏损金额，仅固定金额模式生效（默认 500）。

### 【八】连续亏损暂停

- `InpUseConsecutiveLossPause`：启用连续亏损暂停（默认 `false`）。只统计本 EA、本品种的平仓成交；出现盈利单清零，保本出场中性。
- `InpConsecutiveLossCount`：连续亏损达到该笔数后暂停开仓（默认 3）。
- `InpPauseAfterConsecutiveLossMinutes`：触发后暂停开新仓的分钟数（默认 240）。

### 【九】EA 运行设置

- `InpTimerSeconds`：定时检查间隔，单位秒（默认 10）。行情密集时以 `OnTick` 为主，定时器兜底去重。
- `InpMagic`：魔术号，用于区分本 EA 的订单（默认 20260530）。

## 信号逻辑

### 1. 顺势回调

- H4 不逆向（上涨或转换中），H1 明确趋势。
- M15 回调到 EMA20/EMA60 区间或结构区。
- M5 突破小高/小低确认。
- 止损放 M15 结构外侧（加 `InpSLBufferPoints`），TP1 用 M15 结构目标，TP2 用 2R。

### 2. 突破延续

- H1 最近约 12 根 K 线的箱体（高/低点）被 M15 收盘突破（加 `InpBreakoutBufferPoints` 确认）。
- M5 继续突破小结构确认。
- 止损放箱体边缘外侧（加 `InpSLBufferPoints`）。
- TP1 用箱体高度，TP2 用 2R。

### 3. 反转确认

- H4/H1 原方向较强或处于转换中。
- M15 出现简化 RSI 背离（多头背离要求背离前 RSI ≤ `InpReversalBuyRsiMax`，空头背离要求 ≥ `InpReversalSellRsiMin`）。
- M15 收盘收复/跌破均线（默认要求 EMA60，`InpReversalRequireEMA60=false` 时降为 EMA20）。
- 入场周期突破小高/小低并超过 `InpReversalBreakBufferPoints` 缓冲。
- 建议小仓使用。

## 重要提醒

这个 EA 是交易流程助手，不是稳赚系统。它的作用是把你的规则机械化，帮你减少随手单、追单、没止损的问题。

实盘前必须做：

- 策略测试器回测。
- 模拟盘前向测试。
- 检查 XAUUSD 点值、报价位数、滑点和交易时间。
- 根据你的账户净值改仓位。

## 利润保护建议

如果回测出现“净值冲高、最后结余没保护好”的情况，建议先用这组保守参数重新测试：

- `InpUseBreakEven = true`
- `InpBreakEvenStartPoints = 500`
- `InpBreakEvenLockPoints = 50`
- `InpUseTrailingStop = true`
- `InpTrailStartPoints = 900`
- `InpTrailDistancePoints = 500`
- `InpTrailStepPoints = 100`
- `InpUseEquityProtection = true`
- `InpEquityProtectAnchorMode = ANCHOR_INITIAL_DEPOSIT`
- `InpEquityProtectStartPercent = 4.0`
- `InpEquityGivebackPercent = 25`
- `InpPauseAfterEquityProtectMinutes = 240`

需要更狠的“截断回吐”，可以再加开：

- `InpUseDailyMaxLoss = true`
- `InpDailyMaxLossMode = DAILY_LOSS_PERCENT`
- `InpDailyMaxLossPercent = 5.0`
- `InpUseConsecutiveLossPause = true`
- `InpConsecutiveLossCount = 3`
- `InpPauseAfterConsecutiveLossMinutes = 240`

调参方向：

- 利润被过早扫掉 → 调大 `InpTrailDistancePoints`。
- 回吐仍然太多 → 调小 `InpTrailStartPoints` / `InpTrailDistancePoints`，或调小 `InpEquityGivebackPercent`。
- 移动止盈/保本每次修改止损时，相对上次变化至少要达到 `InpTrailStepPoints` 才会改单。

## 自动交易提醒

当前版本已经可以根据信号自动开仓，并带有多层风控，但它仍然只是规则执行器，不保证盈利。建议顺序：

1. 历史回测。
2. 模拟盘前向测试。
3. 小资金、小风险实盘。
4. 稳定后再优化参数。

## 策略 3 回测没有交易怎么办

如果单独测试 `MODE_REVERSAL_CONFIRMATION`，交易频率本来会比顺势和突破低。V0.1 的确认条件（默认）是：

- M15 出现简化 RSI 背离。
- M15 收盘收复或跌破 EMA60（`InpReversalRequireEMA60` 默认 `true`）。
- 入场周期突破小高点或小低点（加 `InpReversalBreakBufferPoints` 缓冲）。

如果仍然太少，可以优先调这些参数：

- 降低 `InpMinRR`，例如从 `1.5` 改成 `1.2`。
- 增大 `InpMaxSLPoints`。
- 减小 `InpSLBufferPoints`。
- 把 `InpReversalRequireEMA60` 改成 `false`（只需收复/跌破 EMA20，信号会明显变多）。
- 把 `InpSetupTF` 从 M15 改成 M5，把 `InpEntryTF` 改成 M1。

如果策略3开仓太多、质量不够，可以这样调严：

- 保持 `InpReversalRequireEMA60 = true`
- 增大 `InpReversalBreakBufferPoints`，例如 `120 -> 180`
- 降低 `InpReversalBuyRsiMax`，例如 `45 -> 40`
- 提高 `InpReversalSellRsiMin`，例如 `55 -> 60`
